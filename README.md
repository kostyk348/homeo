# homeo — гомеостатический контроллер на инвариантах

Компактное ядро (137 строк, без зависимостей) для балансировки **конкурирующих
инвариантов** в пространстве политики. Порт с C++ (CIDHC, `include/homeo/`).

Вместо "обучать поведение" контроллер каждый тик пере-балансирует набор
инвариантов под текущее состояние среды и возвращает коэффициенты политики
(все координаты нормализованы к `[−1, 1]` и разворачиваются в осмысленные
величины: доли посадок, агрессивность продаж, темп найма и т.п.).

## Как это работает

Поведение задаётся инвариантами `I_j(X)` с весами `w_j(X)`:

```
E(X) = Σ_j w_j(X) · |I_j(X)|^p_j      →  min
```

- **вес может зависеть от состояния или от самого X** (аналитическая функция:
  sigmoid, clamp, кусочные, степенные — никакой нейронки). Так реализуются
  "surrender"-переходы: пока угроза мала, инвариант цели доминирует; выросла —
  перевесил инвариант отступления, и точка равновесия плавно смещается.
- **минимизация** — градиентный спуск (Adam) + термальный шум CLT `(12·U−6)`
  с annealing `T_t = T0·2^(−k·t)` (как в `relaxer.hpp`).
- **численный градиент** через центральные разности автоматически учитывает
  `dW/dX` — само-вес: если вес инварианта зависит от X, минимум не обязан
  совпадать с нулём инварианта, и градиент это честно находит (см.
  `test_self_weight`).

## API

```python
from homeo import HomeoEngine, make_invariant, make_dynamic_invariant

eng = HomeoEngine(
    center=[0.5, 0.5], range_=[0.5, 0.5],          # X0 ∈ [0, 1] каждая
    invariants=[
        make_invariant(1.0, 2, lambda X: X[0] - 0.4),          # цель 0.4
        make_dynamic_invariant(1.0, 2,                          # surrender:
            lambda X: X[1] - 1.0,                              #   "наступать",
            lambda X: 1.0 - threat),                           #   вес падает с угрозой
    ],
    lr=0.2, max_iter=40, grad_tol=1e-4, t0=0.01, seed=42)

eng.set_raw([0.1, 0.1])   # тёплый старт от текущей политики
eng.tick()                # релаксация до сходимости (≤ max_iter шагов)
x = eng.raw()             # развёрнутые коэффициенты политики
```

### Примитивы

| Объект | Назначение |
|---|---|
| `Invariant(weight, p, err, wfn)` | инвариант: `err: X→float`, `wfn: X→float` (по умолчанию 1.0) |
| `make_invariant(weight, p, err)` | статический вес |
| `make_dynamic_invariant(weight, p, err, wfn)` | вес зависит от X / состояния |
| `HomeoEngine(center, range_, invariants, ...)` | релаксация политики |
| `HomeoEngine.tick()` | один проход Adam до сходимости (возвращает число итераций) |
| `HomeoEngine.set_raw(raw)` / `.raw()` | нормализация `[−1,1]` ↔ развёртка |
| `HomeoEngine.reset()` | сброс моментов Adam |

## Установка

```bash
pip install -e .          # пакет homeo-controller
pip install -e ".[test]"  # + pytest
```

Без установки — просто добавь `homeo/` в `PYTHONPATH` (это чистый Python,
только `math` и `random`).

## Тесты

```bash
python -m pytest tests/ -v
```

Три теста перенесены из C++ (`test_bowl.cpp`):

1. **bowl** — двухмерная чаша: сходимость к заданной точке из стартовой.
2. **surrender** — динамические веса: точка равновесия смещается
   `x* = 5 − 10·threat` при росте угрозы.
3. **self-weight** — вес зависит от X: минимум `E = (x−0.5)² + x²·x²` лежит
   в `~3.855`, а не в 5.0 — доказывает учёт `dW/dX`.

## Примеры

```bash
python examples/simple_bowl.py      # сходимость к точке

```

## Боевое применение

Ядро используется в агенте для Kaggriculture (kaggle): `HomeoPolicy` балансирует
6 коэффициентов (плотность посадок wheat, melon, найм рук, агрессивность
продаж, инвестиции в гусей/коров) с инвариантами-фазами сезона:
`plant_rate → target_plant(t)`, `sell_eagerness → давление shed`,
`hire_rate → потребность в руках` и т.д. — средний доход агента ~21k на сид
(бенчмарк v4 — 13.7k).
